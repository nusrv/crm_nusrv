# CLAUDE INTERPRETATION v1 (to be challenged by Codex; static facts only)

Facts I verified this session: `MailTransport.send()` returns `void` (no SMTP response captured); outbox success = status `DELIVERED` (really "SMTP accepted"); non-terminal send failures (timeouts, infra) return the row to QUEUED and are auto-retried (MAX_SEND_ATTEMPTS) — this may conflict with OD-12's "no automatic resend of uncertain reminders"; `MailConfiguration.imapFolder` is a single folder default INBOX, no Sent-folder config; no bounce/DSN/Mailer-Daemon handling anywhere in `modules/mail` (a bounce would ingest like a customer reply); `AuthenticatedUser`/access token carries no session id; roles are ADMIN, ACCOUNTANT, IT, SALES_DEVELOPMENT — there is **no MANAGER role** (owner says "manager"); the refresh cookie path is `/api/v1/auth` (not visible to the Next `/dashboard` proxy); `Payment.invoiceId` is non-null FK; `Invoice.sourceRenewalCaseId` has no writer today.
